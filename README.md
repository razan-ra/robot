Robot Control Panel & Speech-to-Text Interface
مشروع متكامل يقدم واجهة تحكم رسومية وصوتية للتحكم في حركة الروبوت (Forward, Backward, Left, Right, Stop) وتسجيل الأوامر في قاعدة بيانات MySQL بشكل لحظي، مع توفير واجهة برمجية (API) ليستخرج منها الروبوت (مثل ESP32 أو Raspberry Pi) أحدث أمر صادر له.
مميزات المشروع (Features)
 لوحة تحكم بالأزرار (Button Control Pad): واجهة رسومية خفيفة وسريعة للتحكم بأوامر الحركة.
 التحكم الصوتي (Speech-to-Text): تحويل صوت المستخدم إلى نص مفيد وتحديد الأمر التلقائي باستخدام تقنية Web Speech API المدمجة في المتصفح.
 التكامل مع قاعدة البيانات (Database Integration): حفظ الحالات وتحديثها بشكل فوري في جدول منظم بدون تكرار الصفوف.
 حماية وأمان البيانات: استخدام Prepared Statements لتفادي ثغرات الحقن SQL Injection.
 استجابة بتنسيق JSON: سهولة قراءة الأوامر من قبل أجهزة الميكروكنترولر (Microcontrollers).
هيكلية الملفات (Project Structure)
db.php               
الاتصال بقاعدة البيانات (Database Connection)
setup.sql           
سكريبت إعداد قاعدة البيانات والجدول الرئيسي
update_command.php  
 ملف تحديث حالة الروبوت في قاعدة البيانات عبر POST
get_state.php        API لقراءة أمر الحركة الحالي من قبل الروبوت (GET/JSON)
index.html           
واجهة التحكم الرسومية والصوتية (UI + JavaScript)

تفاصيل الملفات (Files Description)
| اسم الملف | الوصف والوظيفة |
|---|---|
| setup.sql | يُنفذ مرة واحدة لإيقاف الجدول robot_state وإضافة الصف الوحيد (id = 1) بالحالة الابتدائية S (Stop). |
| db.php | يحتوي على بيانات واعتمادات الاتصال بقاعدة البيانات MySQL عبر مكتبة mysqli. |
| update_command.php | يستقبل الأوامر المرسلة (forward, left, إلخ) ويحفظها كحروف مختصرة (f, l, إلخ) في الصف id = 1. |
| get_state.php | يقرأ الصف id = 1 ويُرجع نتيجة JSON تحتوي على الحرف الحالي وتاريخ التحديث updated_at. |
| index.html | الواجهة التي تحتوي على أزرار التحكم وخاصية التعرف على الصوت وتحويله لنص وإرساله تلقائياً. |
جدول الأوامر وتخزينها (Command Mapping)
| الأمر بالواجهة / الصوت | الحرف المخزن في قاعدة البيانات | المعنى 
| forward | f | للأمام |
| backward | b | للخلف |
| left | l | يسار |
| right | r | يمين |
| stop | S | توقف |

طريقة التشغيل والتركيب (Setup & Installation)
 إعداد قاعدة البيانات:
   افتح إدارة قاعدة البيانات (مثل phpMyAdmin).
    استورد أو نفّذ الأوامر الموجودة في ملف setup.sql لتجهيز الجدول.
 ضبط بيانات الاتصال:
   افتح ملف db.php وقم بتعديل القيم التالية ببيانات استضافتك:
     $host = "اسم_السيرفر";
$user = "اسم_المستخدم";
$pass = "كلمة_المرور";
$dbname = "اسم_قاعدة_البيانات";

 * تشغيل الواجهة:
   * ارفع جميع الملفات إلى السيرفر الخاص بك (مثل InfinityFree أو XAMPP محلياً).
   * افتح الملف index.html عبر متصفح يدعم خاصية الصوت مثل Google Chrome أو Microsoft Edge.
  اسمح للمتصفح باستخدام الميكروفون عند الضغط على زر التحكم الصوتي .
دورة عمل النظام (System Architecture)
[ المستخدم (User) ]
       │
       ├──► الضغط على الأزرار / التحدث بالصوت 
       │
[ index.html ] 
       │
       ▼ (طلب HTTP POST عبر AJAX)
[ update_command.php ] ───► [ db.php ] ───► [ MySQL: robot_state (id=1) ]
                                                            │
[ الروبوت / ESP32 ] ◄── (طلب JSON GET فترات منتظمة) ─── [ get_state.php ]
